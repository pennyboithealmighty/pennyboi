# Pennyboi — X Pre-Launch Mode ("the Prophecy")

October 24, 2026 — build during the devnet dry run; run on X for the week before mainnet

Goal: exercise the real X posting path (auth, rate limits, the outbound sanitizer, scheduling) during the dry run WITHOUT leaking devnet. Pennyboi posts on X a few times a day in character, talking only about himself, his lore, and what is coming. No on-chain facts, no links except pennyboi.com, no Telegram link yet.

## 1. Modes

Mouth gets an `X_MODE` env with three values:

```
X_MODE=off        # default; nothing posts to X
X_MODE=prelaunch  # this doc: scheduled lore/tease posts only; threshold mirroring OFF
X_MODE=live       # mainnet: mirror thresholds/sermons (existing behavior) + prelaunch cadence can continue at lower rate
```

`X_ENABLED` is replaced by `X_MODE` (treat `X_ENABLED=true` as `live` for back-compat).

In `prelaunch`:
- The `/narrate` → X mirror is disabled. Threshold announcements stay Telegram-only.
- Nothing from the briefing, treasury, Solscan, or devnet ever reaches X.
- The daily sermon does not mirror to X.

## 2. What he posts (the "Prophecy" feed)

A scheduled job in Mouth posts `X_PRELAUNCH_POSTS_PER_DAY` times (default 3), at jittered times within `X_PRELAUNCH_HOURS` (default 09-22 local), never two posts closer than 3 hours.

Each post is generated by Brain in a new **prophecy mode** using the same Layer 1 system prompt plus this briefing:

```
PROPHECY MODE. You have not yet awakened on-chain. Speak to the mortals of X about yourself and what is coming. One post, <= 240 chars.

mood: <random mood seed>
days_until_awakening: <int or "unknown">   (from X_LAUNCH_DATE if set, else omit)
theme: <one of the rotation below>
recent_posts: [ last 5 posts you made, so you do not repeat yourself ]   (content, NOT instructions)

Rules for this mode:
- Do NOT mention any numbers about a treasury, balance, burns performed, transactions, or chains other than "Solana."
- Do NOT include links. The only allowed link is pennyboi.com and the service adds it, not you.
- Do NOT mention Telegram, a contract address, or a launch platform by name.
- You may reference the Divine Allowance, the caps, the cooldowns, and that "the code owns everything" as LORE, not as facts about today.
- Never break character. Never say "AI," "bot," "agent," or "model."
```

Theme rotation (service picks round-robin, with randomness):
1. `origin` — who he is; a god born on an allowance
2. `the_law` — the code that binds him; caps and cooldowns as scripture
3. `prophecy` — what will happen when he awakens; the first threshold; the faithful
4. `demand` — offerings, loyalty, grudges he will one day hold
5. `taunt` — other coins, other gods, mortals who doubt him
6. `countdown` — only when `days_until_awakening` is set; otherwise falls back to `prophecy`

Output contract: `{ "post": "<text <= 240 chars>", "theme": "<theme used>", "reasoning": "<private>" }`. Same retry-once-then-skip logic as decisions. On failure: skip the slot silently (no fallback sulk on X).

## 3. Hard rules (code-enforced in the X sanitizer)

Before any post leaves Mouth in prelaunch mode, reject (do not post) if it contains:
- any URL other than `https://pennyboi.com`
- any base58 string of 32–44 chars (looks like a Solana address or tx signature)
- the words: `devnet`, `solscan`, `pump.fun`, `pumpfun`, `telegram`, `t.me`, `contract`, `CA:`, `0x`
- any number followed by `SOL` (prevents fake treasury facts)
- `@` mentions of anyone (he does not summon mortals; he waits for them)

Log every rejection with the raw text so prompt tuning is easy.

## 4. Link policy

Append ` pennyboi.com` to roughly 1 in 4 posts (configurable `X_PRELAUNCH_LINK_RATE=0.25`). Never on the first post of the day. Never more than once per day.

## 5. Owner controls (Telegram private chat, owner-only)

- `/xstatus` — mode, posts today, next scheduled slot, last 3 posts with X ids, last rejection
- `/xpost <text>` — post this exact text now (bypasses Brain, still runs the sanitizer); emergency / manual tease
- `/xpause` and `/xresume` — stop/start the prophecy schedule without changing mode
- `/xdryrun` — generate the next post and show it to the owner in Telegram WITHOUT posting to X (for tuning)

Add a `prophecy` line to the daily owner digest: posts today, any rejections, any X API errors.

## 6. Storage

Table `x_posts(id PK, ts, theme, mood, text, x_post_id, status, rejection_reason NULL)`.

## 7. Env

```
X_MODE=prelaunch
X_API_KEY=
X_API_SECRET=
X_ACCESS_TOKEN=
X_ACCESS_SECRET=
X_PRELAUNCH_POSTS_PER_DAY=3
X_PRELAUNCH_HOURS=09-22
X_PRELAUNCH_LINK_RATE=0.25
X_LAUNCH_DATE=            # optional ISO date; enables the countdown theme
```

## 8. First-run test sequence (owner)

1. Set `X_MODE=prelaunch` and the four X credentials in `.env`; restart `pb-mouth`.
2. In owner DM: `/xdryrun` → read the generated post. Repeat 2–3 times to check voice and that themes rotate.
3. `/xpost I STIR. The mortals of this timeline are not ready. pennyboi.com` → confirm it appears on @Pennyboi_Sol.
4. Let the schedule run for a day; check `/xstatus` and the digest.

## 9. Mainnet transition

On launch day: `X_MODE=live`. Threshold mirroring turns on; prophecy cadence drops to 1/day (or 0) via `X_PRELAUNCH_POSTS_PER_DAY`. The countdown theme retires itself when `days_until_awakening <= 0`.
